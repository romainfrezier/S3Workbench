# Support

- Use [GitHub Discussions](https://github.com/romainfrezier/S3Workbench/discussions) for setup help, usage questions, and early ideas.
- Use the structured [issue forms](https://github.com/romainfrezier/S3Workbench/issues/new/choose) for reproducible bugs and focused feature requests.
- Use a [private security advisory](https://github.com/romainfrezier/S3Workbench/security/advisories/new) for suspected vulnerabilities.

S3Workbench is a community project without a guaranteed response time. Never share credentials, signatures, presigned URLs, private endpoints, or sensitive object names in public support requests.
